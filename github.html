Latest & Recommended

RunWright

RunWright is a free, open-source GitHub Action — and the only known action (at time of writing) that lets you decide upfront how long your tests should take to finish. It auto-scales GitHub runners based on actual test load, giving you truly dynamic parallelism.

GitHub Action

playwright-load-balancer-based-on-changed-files

Dynamically scales GitHub runners up or down based on the test files touched as part of a pull request, then uses Playwright sharding to distribute tests efficiently across the scaled runners.

View on GitHub Marketplace
GitHub Action

playwright-load-balancer-based-on-tests-to-run

Dynamically scales GitHub runners up or down based on the number of tests to run in a workflow. Uses Playwright sharding to distribute the tests across runners for optimal performance.
